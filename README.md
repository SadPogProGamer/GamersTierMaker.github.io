A web app for creating interactive tier lists — visual rankings for ordering anything from game characters to favorite movies. A close TierMaker-style experience with a drag-and-drop interface.

## 🎮 Features
- Drag & Drop interface — move images between tiers with a single gesture
- Classic rank system — S, A, B, C, D tiers with color coding for clarity
- Image bank — keep all uploaded pictures available for quick access
- Image upload — add your own images to create a unique ranking
- Tier editing — change labels and colors to fit your needs
- Export results — save a finished tier list for sharing on social media
- Reset and clear — start fresh with one click
- Import/Export data — save projects and return to them later
