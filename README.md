# GamersTierMaker

This repository contains a tier list maker web app that can be published with GitHub Pages.

## Live site

https://sadpogprogamer.github.io/GamersTierMaker.github.io/

## How to publish on GitHub Pages

1. Make sure the repository is pushed to GitHub.
2. In GitHub, go to `Settings` > `Pages`.
3. Select the branch `main` (or `master`) and the root folder `/`.
4. Save the settings.
5. Your site will be available at the URL above.

## Notes

- `index.html` now loads the CSS and JavaScript files from the repository root.
- Keep all files in the repository root so the Pages site can serve them correctly.
